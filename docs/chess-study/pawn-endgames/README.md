## 원문 보존 방식

`originals/`는 영문 발췌다. 기보와 해설은 원문을 유지하고 줄바꿈·표·도해 경로를 Markdown에 맞게 바꾸었다. 한국어는 목차와 출처·권리·편집 범위를 설명하는 관리 정보에만 사용한다. 원문에서 수표와 떨어져 인쇄된 일부 도해는 해당 발췌의 끝으로 옮겼다.

수집물의 파일·링크·도해를 확인했다. 원저의 체스 분석을 현대 엔진으로 전수 검증하거나 수정한 자료는 아니다. 원저의 일반화에 관한 간단한 편집 주는 원문과 구분해 표시했다.
